# 自动更新 · By T8star

启动器默认在启动时检查本项目的 GitHub Release；可取消“启动检查更新”。检查失败不会影响训练。发现新版后，空闲时点“安装更新”，下载校验完成后启动器会退出、安装并重开。训练中不能安装更新，请同时关闭本目录其他启动器和 Python 任务。

更新只替换训练器 EXE、程序、文档、Skill 和默认模板。不替换 Python、ComfyUI、模型、对照视频、`local/`、`runs/`、个人路径设置；已存在的 `configs/`、`datasets/`、`examples/` 保留，最新版模板位于 `defaults/`。自己的训练数据仍请放 `local/`。更新不会自动下载大模型或安装依赖。

发布页的 `Windows-NoPython.zip` 既是轻量安装包，也是整合包的程序更新来源。首次用轻量包时，自备 Python 3.10+ 和可运行 H3 编码的 ComfyUI 环境，在界面中选择 Python、ComfyUI、真实 H3 文本编码器；它不含 Python、ComfyUI、大模型或视频。已有完整包用户使用界面更新即可，无需重新下载 Python。

每次更新核对 ZIP 及全部文件的 SHA-256，安装前保存备份到 `local/updater/backups/`。普通安装失败自动回滚，结果见 `local/updater/latest_result.json`。断电或强制结束可能需要人工恢复：先关闭本包所有任务，让 Agent 查看备份目录的 `journal.json`，按 `changed` 清单还原原文件，核实后再清理 `local/updater/install.lock`，不要直接删用户数据。保存的旧代码也可用于继续旧训练；更新后的代码不保证能续训旧 run，计划续训应先保留原环境。

维护者向 `main` 推送后，GitHub Actions 会测试更新器、编译 EXE、发布 `v0.2.<运行编号>` Release，附轻量 ZIP、`update.json` 和 `SHA256SUMS.txt`。发布失败不会更新用户程序。涉及 Python 依赖的升级要更新运行环境兼容编号并另发完整运行包，不能用普通程序更新假装完成依赖升级。

## English

The launcher checks GitHub Releases at startup by default. Turn off the checkbox to disable it. Click Install update while idle; the launcher verifies the download, closes, installs and restarts. Network errors do not block training.

Updates preserve Python, ComfyUI, models, videos, user settings, `local/`, `runs/`, and existing config/data/example files. Current templates are available in `defaults/`. The NoPython ZIP is a lightweight installation and the update payload; new users must supply Python 3.10+, an H3-capable ComfyUI environment and the actual text encoder.

Checksums and per-file verification precede installation. Failed installations roll back automatically; backups and journals are under `local/updater/`. A power interruption may require manual journal-based recovery. Keep the original software environment when resuming an older training run.

Pushing to main automatically builds and publishes a versioned Release through GitHub Actions. Runtime dependency migrations require a separate compatible environment; app updates do not install Python dependencies.
