# Windows训练器使用

保留整个解压目录，双击 `WushuBridge-Trainer.exe`。Windows需要 .NET Framework 4.8。

## 选择对应版本

- 完整整合包：含Python、训练依赖、ComfyUI编码源码和交付中列明的模型/历史视频；大型H3文本编码器与视频主模型另备。
- GitHub `Windows-NoPython.zip`：只含训练器EXE、程序、文档、Skill和公开基础文本，**不含Python、ComfyUI、模型和视频**。选择已有Python 3.10+、PyTorch 2.3+等训练依赖、可运行H3文本编码的ComfyUI环境与实际编码器。视频生成环境仍需自行准备。

## 第一次训练

1. 先看[如何训练](../如何训练.md)，点击“检查环境”。轻量包需手动选运行环境，完整包自动定位内置路径。
2. 自建数据优先选无评分偏好模式，同时替换JSONL和配套分组；8对样例只展示格式。[制作训练集](../训练集制作.md) · [交给Agent](../AGENT交接.md)。
3. 在空闲时开始训练，使用新的编码缓存与输出目录。续训保持原数据、配置、代码和环境。
4. 训练后取得 `bridge.safetensors`、`模型使用说明.md` 和 `inference_settings.json`，按模型说明设置alpha、幅度模式和chunk，不凭文件名猜强度。

## 将 Semantic Bridge 接入现有 ComfyUI

安装最新版[T8 MiniMax H3节点](https://github.com/T8mars/comfyui-minimax-h3-audio-T8)，将桥放入 `ComfyUI/models/semantic_bridge/t8_compat/`，使用Semantic Bridge Config／Apply节点接入H3文本条件。不要放普通 `models/loras/`。文本编码器和视频模型需与部署工作流匹配。

语义桥训练不修改视频主模型；文本诊断或训练完成不等于视频质量通过。按自己的工作流做同提示词、同seed开／关桥对照。

## 更新

启动器默认检查GitHub Release，空闲时点“安装更新”。运行环境、模型、视频、用户数据、设置和已有配置保留，最新模板见 `defaults/`。[更新和恢复说明](自动更新.md)。
